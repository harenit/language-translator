About Scriptorium.

A small translator dashboard, built for reading between languages.

What this is

Scriptorium translates text between languages and dresses the page in the letterforms of whichever language you're reading — pick Tamil and the backdrop fills with Tamil letters, pick Japanese and it fills with kana and kanji, and so on for every supported language.

How it's built

  • Frontend — plain HTML, CSS and JavaScript (no framework), in index.html, style.css and script.js.
  • Backend — a small Node.js/Express API in server.js, organized into controllers, routes, models, config, middleware, services and utils.
  • Translation — the backend proxies requests to the free MyMemory translation API, so no API key is required to try it out.

Making it yours

Use the "Appearance" panel on the left to pick an accent color, switch between light and dark mode, and control how many letters drift across the background. Your choices are saved in this browser automatically.
